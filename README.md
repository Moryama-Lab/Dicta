# Dicta (ディクタ) - 学術・プロフェッショナル専用 音声文字起こし再生スタジオ

> **超高速・完全非破壊・高視認性。伝説のテープ起こしソフト「Okoshiyasu2」の操作性と魂を継承し、現代の最新オーディオ技術とユニバーサルデザインで完全再構築した次世代の文字起こし専用プレイヤー。**

---

## 🌟 Dictaとは

**Dicta（ディクタ）** は、大学・研究機関でのインタビュー調査、オーラルヒストリー、裁判記録、会議録、ジャーナリズム等の現場で膨大な文字起こし（テープ起こし）に携わる研究者・実務家のために開発されたプロ仕様の専用オーディオ再生スタジオです。

2000年代に広く愛用された名作「Okoshiyasu2」の快適なキーボード操作性と自動巻き戻し機能を完全に再現しつつ、現代の Windows 11 環境、大画面高解像度ディスプレイ、高圧縮音声フォーマット（M4A / AAC / FLAC等）、そして微細な声を聞き分ける「精密音響解析・周波数アイソレーター」を搭載して圧倒的な進化を遂げました。

## ✨ 主な特長

### 1. 🛡️ 音声ファイルの100%原本保護（絶対安全・完全非破壊）
- 音声ファイルへの書き込み・上書き保存・メタデータ更新等の破壊的操作は物理的に行いません。
- オーディオエンジンは **完全読み取り専用（Read-Only Stream）** でオープンし、安全に再生します。
- クラウドストレージ（Google Drive, Dropbox, OneDrive等）上の音声ファイルを直接読み込んでも同期競合や破損を起こしません。

### 2. ⚡ C言語ネイティブ再生エンジン（極低レイテンシ ＆ 超軽量）
- 商業DAWやゲーム開発で実績のあるプロ用オーディオライブラリ **BASS 2.4**（64bit Native C）を採用。
- 10時間におよぶ長尺・大容量の音声ファイルでも、メモリ消費量はわずか数十MB。パソコンがフリーズすることなく、瞬時にシーク・頭出し・速度変更が可能です。
- **再生速度変更（0.50倍 〜 2.00倍）**: 音程（ピッチ）を変えずに話速だけを自在にコントロール（0.05倍刻み）。
- **音程調整（±6.0半音）**: 話速とは独立して、低すぎる声・高すぎる声を聴き取りやすい高さに調整可能。
- **一時停止時の自動巻き戻し（オートリワインド）**: 一時停止して再生を再開した際、直前の文脈を失わないよう指定秒数（0.0秒〜5.0秒）だけ自動で巻き戻して再生。

### 3. 🎯 高度な音響解析 ＆ 特定周波数アイソレーター
- **リアルタイム音響解析**: 再生中の音声をミリ秒単位でFFT（高速フーリエ変換）解析し、オシロスコープ波形・周波数スペクトラム・2Dウォーターフォール声紋を表示。
- **特定周波数アイソレーター**: カスケード双二次バンドパスフィルター（BASS_FX）を搭載。周囲の雑音（エアコン・ロードノイズ等）を遮断し、「人の声の特定周波数帯（例: 800Hz〜2500Hz）」だけをピンポイントで抜き出して再生可能。

### 4. ⌨️ 直感的で自由自在なグローバルホットキー
- Word、テキストエディタ、Notion等で文字を入力しながら、**マウスに一切触れずに手元のキーボードだけで再生・停止・巻き戻し・速度変更・時間コピー** が可能です。
- **逐次蓄積型キーボード入力キャプチャ**: 設定画面のボタンをクリックして、手元のキー（Shift, Ctrl, Alt や一般キー）を順番にポンポンと押すだけで、直感的に複数キーの組み合わせショートカットを作成できます。「+ Shift」「+ Ctrl」「+ Alt」「⌫ 1つ消す」「全消去」の画面ボタンからも手軽に編集可能です。
- **自己修復機構**: 他のアプリとホットキーが競合した場合でも、自動的に安全なポーリング方式へと切り替わり、確実に動作し続けます。

### 5. 👁️ ユニバーサルデザイン・高コントラストUI
- 暗所作業や長時間の眼精疲労に配慮した深紺（Deep Navy）とネオンシアンの高コントラスト配色（WCAG AAA準拠）。
- 大きく太いシークバー、高品位アンチエイリアスノブ、明瞭なタイムコード表示。
- 通常の「全画面スタジオモード」と、画面の隅に邪魔にならずに配置できる「コンパクトミニモード」をワンキーで瞬時に切り替え可能。

## 🎹 デフォルトのショートカットキー（推奨設定）

Wordやエディタでの日本語入力と絶対に誤爆・干渉しないよう、デフォルトでは以下の押しやすいショートカットが割り当てられています：

| 機能 | デフォルトキー | 説明 |
| :--- | :--- | :--- |
| **再生 / 一時停止** | `Shift + Ctrl + Alt + W` | 一時停止時に指定秒数（デフォルト1秒）自動巻き戻し |
| **早送り** | `Shift + Ctrl + Alt + E` | 指定秒数（5秒）前進 |
| **巻き戻し** | `Shift + Ctrl + Alt + Q` | 指定秒数（5秒）後退 |
| **等倍に戻す (1.0x)** | `Shift + Ctrl + Alt + Z` | 即座に標準速度（1.00倍）にリセット |
| **速度アップ (+)** | `Shift + Ctrl + Alt + X` | 速度を +0.05倍 加速 |
| **速度ダウン (-)** | `Shift + Ctrl + Alt + A` | 速度を -0.05倍 減速 |
| **最初から** | `Shift + Ctrl + Alt + R` | 最初（A点設定時はA点）へ頭出しジャンプ |
| **時間コピー** | `Shift + Ctrl + Alt + C` | 現在の再生位置をクリップボードにコピー |
| **区間コピー** | 設定画面で割当可能 | `A点 --> B点` のタイムスタンプを一発コピー |
| **時間直接指定** | `Shift + Ctrl + Alt + J` | 秒数・タイムコードを入力して直接ジャンプ |
| **区間リピート A点** | `Shift + Ctrl + Alt + 1` | 聞き取れない箇所の開始点をセット / 解除 |
| **区間リピート B点** | `Shift + Ctrl + Alt + 2` | 聞き取れない箇所の終了点をセット / 解除 |
| **しおり（目印）追加** | `Shift + Ctrl + Alt + B` | 現在位置のシークバー上に黄色い目印を記録 |
| **音量アップ / ダウン** | `Shift + Ctrl + Alt + ↑ / ↓` | マスター音量を微調整 |
| **ミニモード切替** | `Shift + Ctrl + Alt + M` | 全画面 ⇔ 小型ミニプレイヤーの切替 |

> ※ すべてのキー設定は、画面右上の「⚙ キー設定」から自由に変更可能です。

## 🚀 動作環境・インストール方法

### 必要環境
- **OS**: Windows 10 / Windows 11 (64bit)
  - ※ 一般的なあらゆる Windows 10/11 PC（Intel / AMD 64bit）で動作します。
- **Python**: Python 3.10 以上 (64bit推奨)

> **💡 Mac / Linux 環境でご利用になりたい方へ**  
> 本ソフトウェアは、極限の低レイテンシ再生と低負荷な常時バックグラウンドキー監視を実現するため、Windows 64bit Native DLL（BASS 2.4）および Win32 API をネイティブで直接呼び出す設計となっています。  
> Mac (macOS) や Linux 環境へ移植・対応させたい場合は、本リポジトリに同梱されている詳細技術仕様書 **[`SPECIFICATION.md`](SPECIFICATION.md)** を、**Antigravity、Claude Code、Cursor等のAIコーディングアシスタントに読み込ませて**、オーディオエンジン部（BASS for macOS / `libbass.dylib`）およびキーフック部（`pynput` や macOS Cocoa API）の移植版スクリプトを各自生成してご利用ください。アーキテクチャや関数仕様が完全に記載されているため、AIによりスムーズに各OS版を構築可能です。

### セットアップ手順

1. **Pythonのインストール**:
   - [python.org](https://www.python.org/) から最新の Python 3（64bit版）をインストールします。
   - ※ インストール時、「Add Python to PATH（Pythonを環境変数に追加）」に必ずチェックを入れてください。

2. **必要なライブラリのインストール**:
   コマンドプロンプトまたはPowerShellで以下を実行します：
   ```bash
   pip install customtkinter pillow tkinterdnd2
   ```

3. **Dictaの起動**:
   - フォルダ内の `起動_Dicta.bat` をダブルクリックするか、
   - コマンドラインから以下を実行します：
     ```bash
     python dicta.py
     ```

## 📖 便利な使いこなしガイド

### ① カウンターコピー・区間コピー ＆ タイムコード直接ジャンプ
- **時間コピー**: カウンター横の「📋 時間コピー」を押すと、現在位置（例: `01:24:18` または `01:24:18,492`）がクリップボードに入ります。Wordやテキストにそのまま `Ctrl + V` で貼り付けられます。
- **区間コピー**: 「⇥ 区間コピー」を押すと、A点〜B点（またはA点〜現在位置）が `01:30:27,175 --> 01:30:37,420` の形式でコピーされ、発言区間の引用やSRT字幕作成にそのまま使えます。
- **タイムコード直接編集**: 上部の大きな時間表示をクリックすると入力枠に切り替わり、任意の時間（例: `15:30` や `01:20:00`）を入力してEnterキーを押すだけで瞬時にジャンプできます。外側の余白をクリックするかEscキーを押すだけでいつでも変更をキャンセルできます。

### ② シークバー直結のしおり機能
- 音声中の重要な発言や後で聞き返したい箇所で「しおり追加」を押すと、シークバー上に鮮やかな黄色の縦線が刻まれます。
- その縦線をクリックするだけで、いつでもその瞬間へ瞬時に戻ることができます。

### ③ 聞き取りにくい小声・こもり声の強調
- **会話強調プリセット**: イコライザーのプリセットから「クリアボイス」を選ぶと、人の声の子音（4kHz帯）が持ち上がり、モゴモゴした声が明瞭になります。
- **周波数アイソレーター**: 雑音がひどい録音では、解析画面上の声紋部分をドラッグするか、プリセット「会話のみ」「子音・小声」をONにすると、周囲の雑音が消えて声だけが浮き上がります。
