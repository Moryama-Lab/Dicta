# Dicta (ディクタ) - 学術・プロフェッショナル専用 音声文字起こし再生スタジオ

> **超高速・完全原本保護・完全オフライン。現代の最新オーディオエンジニアリングとユニバーサルデザインでゼロから構築された、次世代のテープ起こし専用オーディオスタジオ。**

---

## 🌟 Dictaとは

**Dicta（ディクタ）** は、大学・研究機関でのインタビュー調査、オーラルヒストリー、裁判記録、議事録、ジャーナリズム等の現場で膨大な文字起こし（テープ起こし）に携わる研究者・実務家のために開発されたプロ仕様の専用オーディオ再生スタジオです。長年親しまれてきた文字起こしソフト「Okoshiyasu2」を参考に、現代の最新オーディオエンジニアリングとWindows 11環境に合わせてゼロから再構築しました。

文字入力と絶対に干渉しない快適なキーボード操作性と自動巻き戻し機能を備え、現代の Windows 11 環境、大画面高解像度ディスプレイ、高圧縮音声フォーマット（M4A / AAC / FLAC等）、そして微細な声を聞き分ける「精密音響解析・周波数アイソレーター」を搭載しています。

## 🛡️ 7大設計原則と安全性の保証

### 1. 🛡️ 音声ファイルの100%原本保護（絶対安全・完全非破壊）
- **書き込みハンドルの非存在**: オーディオエンジンは物理的に **完全読み取り専用（Read-Only Stream）** でオープンします。ファイルへの書き込み、上書き保存、ID3タグ編集、メタデータ更新等の破壊的操作は物理的に行いません（エンジン内に書き込み関数すら定義されていません）。
- **完全な安全性**: クラウドストレージ（Google Drive, Dropbox, OneDrive等）上の音声ファイルを直接読み込んでも、同期競合やファイル破損を起こすことは100%ありません。
- **安全キャッシュ再生（SSDアイソレーション）**: ネットワークドライブ上の大容量音声を再生する際も、ローカルSSDの安全な一時領域へ片方向コピー（リードオンリー）して再生するため、回線瞬断やフリーズを完璧に防止します。

### 2. 🔒 完全オフライン ＆ ゼロトラッキング（情報漏洩リスクゼロ）
- **外部通信コードの完全遮断**: 本ソフトウェアには外部サーバーとの通信ライブラリ（requests, urllib, socket, telemetry等）は1行も含まれていません。
- **完全スタンドアロン**: 音声データ、文字起こし内容、キー入力ログ、ファイル履歴がインターネットやAIサーバー、外部企業へ流出することは技術的・物理的に100%不可能です。機密インタビューや未公開調査データも安心して扱えます。

### 3. ⚙️ OSへの非侵入性（デフォルトプレーヤーの勝手な変更は一切行いません）
- **強制的な関連付けの排除**: Dictaをインストール・起動しても、Windowsの「既定のアプリ（デフォルトの音楽プレーヤー）」を勝手に変更・乗っ取ることは絶対にありません。
- **自由な選択肢として登録**: エクスプローラーで音源ファイルを右クリックした際、「プログラムから開く」の選択肢候補にDictaを安全に追加できる機能（設定画面からワンクリックで登録／解除可能）を備えていますが、既存のWindows Media PlayerやiTunes等の設定を崩すことはありません。

### 4. ⚡ C言語ネイティブ再生エンジン（極低レイテンシ ＆ 超軽量）
- 商業DAWやゲーム開発で世界的に実績のあるプロ用オーディオライブラリ **BASS 2.4**（64bit Native C）を採用。
- 10時間におよぶ長尺・大容量の音声ファイルでも、メモリ消費量はわずか数十MB。PythonのGIL（排他ロック）を一切介さないため、パソコンがフリーズすることなく、瞬時にシーク・頭出し・速度変更が可能です。
- **再生速度変更（0.20倍 〜 3.00倍）**: 音程（ピッチ）を変えずに話速だけを自在にコントロール（0.05倍刻み）。
- **音程調整（±6.0半音）**: 話速とは独立して、低すぎる声・高すぎる声を聴き取りやすい高さに調整可能。
- **一時停止時の自動巻き戻し（オートリワインド）**: 一時停止して再生を再開した際、直前の文脈を失わないよう指定秒数（デフォルト1.0秒）だけ自動で巻き戻して再生。

### 5. 🎯 高度な精密音響解析 ＆ 特定周波数アイソレーター
- **3モードのリアルタイム音響解析**:
  - **波形＋スペクトル**: オシロスコープ波形と44バンド周波数スペクトラムを同時表示。
  - **倍音・ピーク**: 話者の声帯基本周波数・母音/子音帯域ガイド、連続スペクトル曲線、最大ピークホールド残像（主成分Hz表示）、対称エンベロープ波形を表示。
  - **スペクトログラム**: 時間経過に伴う声紋ヒートマップ（2Dウォーターフォール）を表示。
- **特定周波数アイソレーター（枠のドラッグ伸縮対応）**: カスケード双二次バンドパスフィルター（BASS_FX）を搭載。周囲の雑音（エアコン・ロードノイズ等）を遮断し、「人の声の特定周波数帯」だけをピンポイントで抜き出して再生可能。解析画面上の黄色い選択枠の左右端をマウスで引っ張ることで、抜き出す周波数帯域の幅を直感的に広げたり狭めたりカスタマイズできます。

### 6. ⌨️ 直感的で確実なグローバルホットキー設定
- Word、テキストエディタ、Notion等で文字を入力しながら、**マウスに一切触れずに手元のキーボードだけで再生・停止・巻き戻し・速度変更・時間コピー** が可能です。
- **選択式の確実なキー設定**: 設定画面（⌨ キー設定タブ）から、`Shift` `Ctrl` `Alt` のチェックボックスとキー一覧（F1〜F12、英数字、方向キー、テンキー、無変換/変換など）をマウスで選ぶだけで、100%確実に思い通りのキーを割り当て可能。重複も自動警告されます。
- **自己修復機構**: 他のアプリとホットキーが競合した場合でも、自動的に安全なポーリング方式へと切り替わり、確実に動作し続けます。

### 7. 🖥️ マルチモニター（画面拡張）最適化 ＆ 高視認性デザイン
- **画面拡張対応**: ノートPCと外付け大型モニター間をウィンドウが移動しても、ウィンドウサイズが急変したりカクついたりしない System DPI Aware 設計。
- **視覚疲労軽減**: 暗所作業や長時間の眼精疲労に配慮した深紺（Deep Navy）とネオンシアンの高コントラスト配色（WCAG AAA準拠）。

## 💡 推奨ワークフロー：6キー程度の「片手マクロキーボード」との連携

Dicta のポテンシャルを最大限に引き出す運用として、Amazon等で販売されている **6キー程度のプログラマブル片手キーボード（マクロパッド）** を購入し、Dicta と組み合わせて手元に配置するスタイルを強く推奨しています。

- **なぜデフォルトが `Shift + Ctrl + Alt + ...` なのか？**:
  Wordやテキストエディタでの文字入力・既存のショートカット（`Ctrl+C` や `Ctrl+Z` 等）を絶対に妨げないための専用キー割り当てです。この複合キーを片手キーボードの6つのボタンにあらかじめ記憶させておくことで、メインのキーボードで文字を打ちながら、指先ひとつ（ワンボタン）で「再生/停止」「5秒戻る」「5秒進む」「時間コピー」「速度変更」などをストレスなく瞬時に操作できます。
- **フットペダル（足踏みペダル）との比較**:
  お好みで市販のUSBフットペダルを割り当てて使うことも可能ですが、フットペダルは構造上3つ程度しかスイッチを動かせないため、割り当てられる操作が限られます。6キー前後の片手キーボードであれば、再生・巻き戻し・早送りに加えて「時間コピー」「しおり追加」「最初から」など文字起こしに必要な主要操作をすべて手元で完結できるため、圧倒的に快適です。

## 🎹 デフォルトのショートカットキー（推奨設定）

Wordやエディタでの日本語入力と絶対に誤爆・干渉しないよう、デフォルトでは以下の押しやすいショートカットが割り当てられています：

| 機能 | デフォルトキー | 説明 |
| :--- | :--- | :--- |
| **再生 / 一時停止** | `Shift + Ctrl + Alt + W` | 一時停止時に指定秒数（デフォルト1秒）自動巻き戻し |
| **早送り** | `Shift + Ctrl + Alt + E` | 指定秒数（5秒）前進 |
| **巻き戻し** | `Shift + Ctrl + Alt + Q` | 指定秒数（5秒）後退 |
| **等倍に戻す (1.0x)** | `Shift + Ctrl + Alt + Z` | 即座に標準速度（1.00倍）にリセット |
| **速度アップ (+)** | `Shift + Ctrl + Alt + X` | 速度を +0.05倍 加速 |
| **速度ダウン (-)** | `Shift + Ctrl + Alt + A` | 速度を -0.05倍 減速 |
| **最初から** | `Shift + Ctrl + Alt + R` | 最初（A点設定時はA点）へ頭出しジャンプ |
| **時間コピー** | `Shift + Ctrl + Alt + C` | 現在の再生位置をクリップボードにコピー |
| **区間コピー** | 設定画面で割当可能 | `A点 --> B点` のタイムスタンプを一発コピー |
| **時間直接指定** | `Shift + Ctrl + Alt + J` | 秒数・タイムコードを入力して直接ジャンプ |
| **区間リピート A点** | `Shift + Ctrl + Alt + 1` | 聞き取れない箇所の開始点をセット / 解除 |
| **区間リピート B点** | `Shift + Ctrl + Alt + 2` | 聞き取れない箇所の終了点をセット / 解除 |
| **しおり（目印）追加** | `Shift + Ctrl + Alt + B` | 現在位置のシークバー上に黄色い目印を記録 |
| **音量アップ / ダウン** | `Shift + Ctrl + Alt + ↑ / ↓` | マスター音量を微調整 |
| **ミニモード切替** | `Shift + Ctrl + Alt + M` | 全画面 ⇔ 小型ミニプレイヤーの切替 |

## 🚀 動作環境・インストール方法

### 必要環境
- **OS**: Windows 10 / Windows 11 (64bit)
  - ※ 一般的なあらゆる Windows 10/11 PC（Intel / AMD 64bit）で動作します。
- **Python**: Python 3.10 以上 (64bit推奨)

> **💡 Mac / Linux 環境でご利用になりたい方へ**  
> 本ソフトウェアは、極限の低レイテンシ再生と低負荷な常時バックグラウンドキー監視を実現するため、Windows 64bit Native DLL（BASS 2.4）および Win32 API をネイティブで直接呼び出す設計となっています。  
> Mac (macOS) や Linux 環境へ移植・対応させたい場合は、本リポジトリに同梱されている詳細技術仕様書 **[`SPECIFICATION.md`](SPECIFICATION.md)** を、**Antigravity、Claude Code、Cursor等のAIコーディングアシスタントに読み込ませて**、オーディオエンジン部（BASS for macOS / `libbass.dylib`）およびキーフック部（`pynput` や macOS Cocoa API）の移植版スクリプトを各自生成してご利用ください。アーキテクチャや関数仕様が完全に記載されているため、AIによりスムーズに各OS版を構築可能です。

### セットアップ手順（簡単3ステップ）

1. **Pythonのインストール**:
   - [python.org](https://www.python.org/) から最新の Python 3（64bit版）をインストールします。
   - ※ インストール画面で **「Add python.exe to PATH」** にチェックを入れてください。

2. **必要なライブラリのインストール**:
   - コマンドプロンプトまたはPowerShellを開き、Dictaのフォルダ内で以下を実行します：
     ```bash
     pip install -r requirements.txt
     ```

3. **Dictaの起動**:
   - フォルダ内の **`Dicta.exe`** をダブルクリックするだけで即座にお使いいただけます（または `python dicta.py`）。
   - ※ デスクトップにショートカットを置きたい場合は、`Dicta.exe` を右クリックして「送る ➔ デスクトップ（ショートカットを作成）」するか、Dicta画面内の「設定・キー」からワンクリックで作成できます。

4. **エクスプローラーの「プログラムから開く」に登録する場合（任意）**:
   - 音源ファイルを右クリックして直接 Dicta で開きたい場合は、Dicta 画面右上の「⚙ 設定・キー」➔「⚙ 再生・コピー・安全設定」タブを開き、**「『プログラムから開く』に登録する」** ボタンをクリックします。
   - ※ 既定のアプリ（デフォルトプレーヤー）は一切変更されず、右クリックメニューの選択肢候補にのみ追加されます。不要になった際はワンクリックでいつでも解除できます。

Dicta は、他の研究者や文字起こしアシスタントの方にも極めて簡単に共有・配布できるよう設計されています。配布用リポジトリには開発者の個人ファイルや再生履歴は一切含まれていません。

### 【共有手順】
1. **GitHubリポジトリを案内する場合**:
   - 共有相手に以下のURLを伝えます：  
     👉 **https://github.com/Moryama-Lab/Dicta**
   - 相手は緑色の「**Code**」ボタン ➔ 「**Download ZIP**」をクリックしてZIPファイルをダウンロードし、解凍するだけで利用できます。
   - （Gitを使える方であれば `git clone https://github.com/Moryama-Lab/Dicta.git` でも可能です）

2. **USBメモリや共有ドライブで直接渡す場合**:
   - 本フォルダ（`dicta/`）をそのままZIP圧縮して渡すか、USBメモリにコピーして渡してください。
   - ※ ローカル設定ファイル（`config.json`）は自動的にGit除外されており、相手のPCで起動した際は初期テンプレート（`config.default.json`）から真っ新な状態で自動起動するため、あなたのプライバシーや再生履歴が漏れる心配は一切ありません。

3. **相手のPCでの初回起動**:
   - 上記の「セットアップ手順」（Pythonとライブラリのインストール）を行っていただき、フォルダ内の `Dicta.exe` をダブルクリックするだけで即座にお使いいただけます。

## 📖 便利な使いこなしガイド

### ① カウンターコピー・区間コピー ＆ タイムコード直接ジャンプ
- **時間コピー**: カウンター横の「📋 時間コピー」を押すと、現在位置（例: `01:24:18` または `01:24:18,492`）がクリップボードに入ります。Wordやテキストにそのまま `Ctrl + V` で貼り付けられます。
- **区間コピー**: 「⏱ 区間コピー」を押すと、A点〜B点（またはA点〜現在位置）が `01:30:27,175 --> 01:30:37,420` の形式でコピーされ、発言区間の引用やSRT字幕作成にそのまま使えます。
- **タイムコード直接編集**: 上部の大きな時間表示をクリックすると入力枠に切り替わり、任意の時間（例: `15:30` や `01:20:00`）を入力してEnterキーを押すだけで瞬時にジャンプできます。外側の余白をクリックするかEscキーを押すだけでいつでも変更をキャンセルできます。

### ② シークバー直結のしおり機能 ＆ 美しい一括消去モーダル
- 音声中の重要な発言や後で聞き返したい箇所で「しおり追加」を押すと、シークバー上に鮮やかな黄色の縦線が刻まれます。
- その縦線をクリックするだけで、いつでもその瞬間へ瞬時に戻ることができます。
- 「全消去」を押した際は、誤操作を防ぐ安全なダークモーダル確認画面が開き、登録されているしおりの件数を確認した上で一括消去できます。

### ③ 音量ブースト（最大200%デジタル増幅 ＆ 限界突破ストッパー）
- 録音レベルが極端に低く聞き取りにくい音声のために、**最大200%（+6dB）のソフトウェア音量ブースト**を搭載しています。
- 音声ファイル原本を改変・上書きすることなく、再生ストリーム上でリアルタイムにデジタル増幅します。
- **限界突破の安全設計**: 通常音量（100%）を超えるラインに引き上げようとした際は、不意の大音量や音割れによる耳・スピーカーへの負担を防ぐため、必ず確認ダイアログが作動して注意を喚起します。承認後はスライダーや数値が警告オレンジ・赤に変化し、安全かつ自在に小声を増幅して聴取できます。

### ④ 聞き取りにくい小声・こもり声の強調と範囲カスタマイズ
- **会話強調プリセット**: イコライザーのプリセットから「クリアボイス」を選ぶと、人の声の子音（4kHz帯）が持ち上がり、モゴモゴした声が明瞭になります。
- **周波数アイソレーター ＆ 黄色枠ドラッグ伸縮**: 雑音がひどい録音では、解析画面をクリックするかプリセット「会話のみ」「子音・小声」をONにすると、周囲の雑音が消えて声だけが浮き上がります。黄色い選択枠の左右の端をマウスで引っ張ることで、抽出する周波数帯の広さを自由自在に調整できます。
